# Test corpus: CEN EN 16931 UBL 1.3.17

Derived from the official CEN/TC 434 validation artefacts vendored in
`artefacts/cen-en16931-ubl-1.3.17/` (tag `validation-1.3.17`, commit
`6e35e0ab8b09eb183f7d84b282e24ef95f9f5715`; see the README there).

## Contents

- `cases.tsv`: every case: 19 example documents, 29 whole test documents and 1131 documents
  extracted from the VEFA unit test sets, with the rule ids each VEFA test expects.
- `vefa/`: the extracted documents, one per `<test>`.
- `golden/`: the expected result of each case, Saxon-HE 12.10 running
  `ubl/xslt/EN16931-UBL-validation.xslt`, in the canonical form described in
  `../SVRL-CANONICAL.md`.
- `vefa-disagreements.tsv`: the cases where the goldens and the VEFA expectations disagree, each
  with its explanation (none for this release).
- `xpath/`: the expression oracle of `crates/einvoice-xpath-eval` (see
  `crates/einvoice-xpath-eval/tests/oracle/README.md`): `documents.tsv`, the cases whose
  documents are used, and `expected.tsv`, Saxon-HE 9.9.1-8's value of every distinct XPath
  expression of `ubl/xslt/EN16931-UBL-validation.xslt` at nodes its template matches in those
  documents.

`cases.tsv`, `vefa/` and `LICENSE.txt` are generated by `cargo xtask corpus --write`, the goldens
by `cargo xtask oracle --write`; see `../README.md`. `xpath/` is generated by the `saxon-oracle`
example of `einvoice-xpath-eval`.
